# 问答式学习小程序 · 开发规划

这是一个基于个人学习资料的问答式学习微信小程序，目前仍在开发中。本仓库用于展示从模糊需求到开发与验收规划的过程，包含四份规划文档。

## 建议阅读顺序

| 文档 | 回答的问题 | 主要内容 |
| --- | --- | --- |
| [spec.md](spec.md) | 做什么、做到什么程度 | 使用对象、目标、输入输出、首版范围、限制与验收标准 |
| [plan.md](plan.md) | 怎么实现 | 架构、模块、接口、数据结构、技术选择与验证策略 |
| [task.md](task.md) | 按什么顺序推进 | 任务依赖、具体步骤、交付内容与验证方式 |
| [checklist.md](checklist.md) | 如何判断完成 | 正常流程、边界情况、完整使用场景及逐项验证状态 |

## 项目目标

用户导入自己的资料后，可以选择“初学模式”进行讲解与复述反馈，或选择“复习模式”进行提问、回答与纠错。首版计划支持文字与轮流语音交流，并区分资料依据与 AI 补充内容。

## 工作方法

先澄清目标、边界和验收标准，再确定实现方案；将方案拆成有顺序、有依赖关系的小任务，并为任务设置验证方式。最后用检查清单记录通过、未通过和未验证的内容，依据验证结果继续迭代。
